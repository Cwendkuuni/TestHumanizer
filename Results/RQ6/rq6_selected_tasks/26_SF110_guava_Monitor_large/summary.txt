     - `enterIf(Guard guard)`, `enterIfInterruptibly(Guard guard)`: Acquire the lock only if the `Guard` condition is satisfied upon entry, with an interruptible variant.
     - `leave()`: Releases the lock and signals the next waiting thread if any.
     - `waitFor(Guard guard)`, `waitForUninterruptibly(Guard guard)`: Waits for the `Guard` condition to be satisfied while holding the lock, with one supporting interruptions.
     - `await(Guard guard, boolean signalBeforeWaiting)`, `awaitUninterruptibly(Guard guard, boolean signalBeforeWaiting)`: Helper methods for waiting on a condition, with or without handling interruptions.
     - `awaitNanos(Guard guard, long nanos, boolean signalBeforeWaiting)`: Waits for a condition to be satisfied within a given timeout.

     - `activeGuards`: A linked list of active `Guard` objects, managed by the lock to track waiting conditions.

   - Condition Waiting Methods: `enterWhen`, `enterWhenUninterruptibly`, `waitFor`, and their timed variants manage waiting based on `Guard` conditions.
   - Helper Methods: `await`, `awaitUninterruptibly`, and `awaitNanos` are used internally to manage condition waiting logic in a synchronized manner.

   - Lock Management: The class provides methods to acquire and release a lock (`enter`, `leave`), supporting various strategies for managing thread access and interruptions.
   - Condition Synchronization: Methods like `enterWhen`, `waitFor`, and their variants allow threads to wait for specific conditions, encapsulated by `Guard` objects, to be met, enhancing control over thread execution flow.
